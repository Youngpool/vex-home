# Changelog

Versions are the preview artifact's versions. Earlier versions (up to v84) built the one-screen home: Kimm in Live2D, the chat engine, the vEXIT key and bars, the risk arc, the dial menu, the Hairline loader, the cursor and the Tutorial reel.

| Version | Change |
|---|---|

| v86 | Smooth resizing: Live2D renderer synced, bars resampled, no transitions while resizing, crossfade on layout mode change |
| v87 | Header keys are words only (icons removed from Whitelist and Download) |
| v88 | Large screens: Kimm framed closer the bigger the screen, aligned to the arc; collapsible history rail on the far left |
| v89 | Selected rail row: no border, a dark grey gradient from 100% to 0% |

| v91 | Recent-order icons removed from the collapsed rail |

| v95 | Design system inside the dial menu: principles, colour, type, layout, components, icons, motion, character, voice |
| v96 | Cursor above every layer; New chat always works (voids a running or pending order); the idle nudge waits while you type |
